# 슬라이드 뷰어

이미지로 캡처한 슬라이드를 브라우저에서 열람·관리하는 도구입니다. 별도 설치 없이 정적 파일로 동작하며, 편집(업로드/순서변경/전체삭제)이 필요할 때만 로컬 서버를 켭니다.

## 사용법

### 편집 (업로드 · 순서변경 · 전체삭제)
`프로그램 시작.bat`을 더블클릭하면 로컬 서버가 실행되고 브라우저가 자동으로 열립니다. Node.js가 설치되어 있어야 합니다.

- 업로드한 이미지는 `images/` 폴더에 실제 파일로 저장되고, `slides.json`에 순서·이름이 기록됩니다.
- 이 서버는 `localhost`에서만 접속되는 로컬 전용 프로그램입니다. 외부에 노출되지 않습니다.

### 보기 전용 (서버 없이)
`index.html`을 더블클릭해서 바로 열어도 이미지가 그대로 보입니다. 이 경우 편집 기능(추가/순서변경/전체삭제)은 숨겨지고 열람만 가능합니다. `images/`, `slides.json`, `slides-data.js`가 포함된 폴더 전체를 압축해서 공유하면, 받는 사람도 설치 없이 바로 열람할 수 있습니다.

## 기술 스택
- 순수 HTML/CSS/JS (프레임워크 없음)
- 편집 서버: Node.js 내장 `http` 모듈만 사용 (외부 의존성 없음)

## 파일 구성
| 파일 | 역할 |
|---|---|
| `index.html` / `style.css` / `app.js` | 뷰어 UI 및 클라이언트 로직 |
| `server.js` | 로컬 편집 서버 (업로드/삭제/순서변경 API) |
| `프로그램 시작.bat` | 편집 서버 실행 + 브라우저 자동 실행 |
| `images/`, `slides.json`, `slides-data.js` | 실제 슬라이드 데이터 (저장소에는 포함되지 않음, `.gitignore` 참고) |
